Para la implementación del entorno experimental se desarrolló un laboratorio físico controlado, diseñado bajo una red de área local (LAN) aislada, donde se simularon ataques de manera segura sin interferencias externas de la red universitaria a fin de evitar falsos posiitivos y riesgos de seguridad.\\
Para la aquitectura de red se basó en una topología física en estrella, interconectando un servidor de monitoreo central y cuatro estaciones de ataque mediante un witch Ethernet y cableado UTP.\\
Mientras el servidor de monitoreo consistió en una computadora de escritorio con un entorno limpio dedicada exclusivamente a hospedar la plataforma de ciberguridad T-Pot, las estaciones de ataque fueron cuatro computadoras portátiles independientes, con sistema Linux y Windows, cada una configurada con diferentes formas de ataque cibernético, de las cuales se ejecutaron escaneos de puertos, intentos de fuerza bruta y pruebas de denegación de servicio (DoS).\\
En el servidor se instaló Ubuntu Server 24.04.3 LTS como sistema operativo base, debido a su estabilidad y compatibilidad con contenedores Docker, sobre el cual se desplegó T-Pot, una plataforma que integra multiples honeypots y herramientas de análisis de seguridad en un entorno unificado, facilitando la observacion, la captura detallada de interacciones maliciosas y el registro automatizado de bitácoras.\\
Por motivo de no exponer la red universitaria a posibles amenazas, se configuró una red interna cerrada, asi que, toda la actividad maliciosa registrada provino de direcciones IP locales, simulando amenazas internas, permitiendo identificar y estudiar patrones de ataque como escaneos de puertos, fuerza bruta contra SSH y ataques de inundación (flood).\\
El entorno experimental se mantuvo aislado y controlado durante todo el proceso, permitió analizar de forma segura y controlada distintos tipos de ataques cibernéticos dentro de una red LAN aislada, dicho entorno puesto en prática demostró la utilidad para la detección, análisis de intrusiones y el fortalecimiento de estrategias de seguridad en centros informáticos.
